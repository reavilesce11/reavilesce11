## Public work

### [Metadata Quality Pipeline](https://github.com/reavilesce11/metadata-quality-pipeline)

![Quality dashboard generated by the pipeline from synthetic episode data](https://raw.githubusercontent.com/reavilesce11/metadata-quality-pipeline/main/docs/dashboard.png)

A reproducible pipeline built entirely on synthetic entertainment metadata. It ingests messy records, preserves the raw values, normalizes fields, applies deterministic quality rules, routes ambiguous cases to a human review queue with an explicit reason, stores an audit history in SQLite, and generates SQL reports and an HTML dashboard.

Clone it and run it: you will get the numbers below, because they are produced by the committed dataset and nothing is edited by hand.

**10 records → 3 accepted, 5 sent to review, 2 rejected, 8 documented issues.**

Eighteen automated tests cover normalization, validation, routing, SQLite persistence, output separation, and duplicate provider IDs. Five of them test the publication guard itself: three force it to reject a committed secret, a local path and a forbidden filename; one confirms an ordinary file produces no findings; and one proves the guard does not exempt its own test suite. GitHub Actions runs the whole thing on Python 3.11 and 3.12 on every push.

### [Reloop — AI-assisted engineering research](https://github.com/reavilesce11/reloop)

Reloop is a local-first orchestration system where two CLI-based AI coding assistants can work on the same task and audit each other under explicit human control. Markdown remains the readable source of truth, SQLite provides a rebuildable index, and privacy checks inspect every package prepared for an external agent.

The project focuses on measurable engineering problems: duplicated context, stale responses, unbounded sessions, concurrency failures, and excessive idle traffic. Its public version includes 138 automated tests and documents the evidence behind each before-and-after result.

## How I work

Evidence before conclusions. Root cause before fixes. Small, reversible changes, one logical change per commit. Hypotheses are marked confirmed, refuted, partial or indeterminate — killing a false hypothesis counts as progress. A small sample is a trend, not a law. Every number cites its source.

I use AI assistants to generate hypotheses, examine counterexamples, review changes, and summarize evidence. Their output is never accepted on authority: I verify it through tests, source evidence, reproducible runs, and human review.
